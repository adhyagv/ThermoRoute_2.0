# Project Abstract — ThermoRoute

ThermoRoute is a climate-aware route intelligence prototype for urban mobility, initially focused on Bengaluru, India. Conventional route planners primarily optimize travel distance or estimated time. ThermoRoute extends route comparison by considering modelled environmental conditions encountered along a journey, including apparent temperature, ultraviolet index, air quality, mapped shade opportunities and precipitation context.

The frontend is built with React, TypeScript, Vite and MapLibre GL JS, with a Three.js concept visualization. The backend uses Python and FastAPI. Road-network geometry and turn instructions are obtained from an OSRM-compatible service using OpenStreetMap data. Nominatim is used for place geocoding. Open-Meteo provides hourly weather forecasts, and its air-quality service provides CAMS-derived air-quality model data. OpenStreetMap features are queried to identify nearby buildings, trees, tree rows, tunnels and fords.

For route analysis, the application samples the route geometry at approximately equal intervals, allocates the total routing-engine duration proportionally across the intervals, and matches each point's predicted arrival time to the nearest available hourly forecast. A solar-position approximation and mapped building/tree features are used to estimate likely shade. A transparent weighted index combines available heat, UV, air-quality and shade-penalty components. Different profile presets alter the relative weights. The backend also evaluates departure candidates in 30-minute increments over a six-hour window and identifies the lowest-scoring candidate when sufficient forecast data is available.

A Civic module allows users to submit geotagged observations such as excessive heat, lack of shade, waterlogging, broken signals and unsafe crossings. Reports are stored in a local SQLite database and displayed as map markers. The platform labels data as Forecast, Estimated, Live, Fallback or Demo so that model outputs, heuristic estimates, local reports and synthetic visual content are not confused.

ThermoRoute is an experimental decision-support system. Its forecasts are grid-cell model outputs; shade and waterlogging are estimates based on incomplete mapping; route times exclude live congestion; civic reports are unverified; and the exposure index is not medically validated. It is intended to demonstrate transparent geospatial data integration and explainable route comparison, not to replace safety-critical navigation or health advice.
